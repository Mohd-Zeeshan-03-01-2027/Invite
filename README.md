# Zeeshan & Ayesha — Wedding Invitation

A responsive, four-section wedding invitation website made for GitHub Pages. It uses the four supplied invitation images without changing their artwork or colour palette, with gentle scroll reveals and optional floating white petals.

## Preview locally

Open `index.html` in a browser. For the most reliable local preview, run a simple static server from this folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a new GitHub repository (for example, `zeeshan-ayesha-wedding`).
2. Upload **all contents** of this folder, keeping the `assets` folder alongside `index.html`.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. GitHub will show your public website URL after deployment finishes.

No build step or framework is required. The Google font is optional; if it cannot load, the site falls back to Georgia.
